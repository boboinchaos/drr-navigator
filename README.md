# DRR Resource Navigator

Find local, state and federal assistance and advocacy programs for any Alabama county, build a Help Action Plan, and save or email it.

Live site: https://boboinchaos.github.io/drr-navigator/

- `index.html` - the whole website (no client data is stored here).
- `backend-Code.gs` - the Google Apps Script backend for saving to Airtable, emailing PDFs and shared resource updates. The passcode and Airtable token live in Script properties, never in this repo.
